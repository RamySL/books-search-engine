# Mots vides anglais : mots grammaticaux, trop fréquents pour distinguer un
# livre d'un autre. Un mot par ligne, en minuscules ; les lignes vides et
# celles qui commencent par # sont ignorées. Les mots d'une lettre (a, i) n'y
# figurent pas : le tokeniseur les écarte tous.
#
# Base : la liste anglaise du projet Snowball (snowballstem.org). Les formes
# contractées (don't, they're) y sont remplacées par les morceaux que laisse
# le découpage sur les apostrophes, et quelques formes archaïques, fréquentes
# dans les livres anciens, sont ajoutées. Comme dans Snowball, les auxiliaires
# qui ont un homonyme courant restent indexés : will, can, may, might, must.
